# Enterprise HR AI Platform

Production-grade AI Platform for Workforce Retention, Engagement Intelligence, Capability Development, Career Progression, and HR Policy Governance.

- **Frontend:** Streamlit interactive executive portal on port 7860
- **Backend:** FastAPI multi-agent orchestration service on port 8000
- **Orchestrator:** Global LangGraph deterministic intent router
- **Specialized Agents:**
  1. Policy Agent (HR Policy RAG with BGE, BM25, and Cross-Encoder)
  2. Workforce Intelligence Agent (Attrition risk prediction and engagement KPIs)
  3. Upskilling Agent (O*NET benchmark gap analysis and course catalog recommendations)
  4. Career Agent (Role career progression pathways and promotion readiness)
  5. HR Operations Agent (Administrative employee records and departmental staffing)
